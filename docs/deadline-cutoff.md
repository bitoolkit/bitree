# DDL 每日伪截止时间段

## 时间规则

设置默认关闭，预置每日 22:00–次日 08:00。开关、开始和结束分钟作为一份
JSON 设置保存；关闭仍保留所选时间。时间选择页常驻原生 Material 表盘，
也保留开始/结束的 HH:mm 填写框；表盘可原生切换为键盘模式。公开控件的
表盘草稿在点击“确定”时保存，取消只恢复当前选择，不退出设置页。

区间两端包含：开始早于结束时匹配同一天；开始晚于结束时匹配跨日区间，
凌晨截止归到前一天的开始时间。开始与结束相同时仅匹配该时间点，不代表
全天。设置精度是分钟，边界时刻为该分钟的 00 秒：结束时刻包含，但其后
的秒和微秒不包含。

只对有真实截止时间的 DDL 生效；普通日程、考试、仅开始时间的测验不变。
全天 DDL 的真实截止仍按原规则视为下一天 00:00，因此也可命中跨日窗口。

## 数据与显示

`AgendaEntry.startsAt`、`allDay` 及序列化内容保持原始数据。
`realDueAt` 是原始截止；`dueAt` 是派生有效截止；`scheduledAt` 用于实际
调整后的日期分组和排序。生效配置只作为运行时投影，不写回日程存储。
关闭或更改设置总是从原始时间重算，不能累计伪提前，也不改变平台链接、
提交状态或同步匹配。

命中窗口与实际提前分开表示：起点或单时间点命中时，即使没有提前，仍需
处理两条标线的绘制顺序。详情中实际发生提前时同时说明有效和真实截止，
编辑器继续编辑原始时间。

## 泳道图

命中窗口的 DDL：

- 全局排版宽度 `D` 在设置中配置，默认 4 天、范围 1–30 天；统一覆盖旧的
  单条拖尾设置，旧 `tailDays` 数据仍保留兼容。
- 预留区间为 `[有效截止 − D 天, 真实截止]`。
- 左侧主体为最小缩放 `D − 0.25` 天的屏幕定宽，不随缩放增长（默认
  3.75 天）；右边界位于有效截止。
- 两条标线之间按真实时间间距绘制矩形，宽度跟随时间轴缩放。
- 填充为屏幕定宽的 45° 宽斜纹，同一配色、交替透明度；完成后再衰减。
- 真实标线未完成时使用原标线的 0.5 透明度，完成后再衰减为 0.25。
- 真实标线在最上层绘制，包括零间距或小于标线宽度的情况；零间距没有
  斜纹区域。有效标线及左侧主体保留正常完成/逾期规则。
- 延伸段按视口裁剪，不能创建按时间跨度无限扩大的画布；全局泳道高度
  规则保持不变。

## 日程与考试的泳道样式

普通日程和考试的左侧信息区同样使用全局 `D` 天预留及 `D − 0.25` 基线天
的屏幕定宽，整体占位为 `[真实开始 − D 天, 真实结束]`。真实时段由开始、
结束两条 3px 实线框住，其间是 45° 双色宽斜纹（实填充色与高亮色两带
全不透明交替，自开始标线起首带为实色），按实际时距缩放；左侧同样是
45° 斜纹（两带交替使用实填充色与其 0.5 半透明）及向内绘制的 1.5px
高亮色（accent）边框。两条时间线重合时结束线最后绘制。所有区域保持
视口裁剪，日期与真实时距不因左侧信息区预留而改变。设置中的“日程与
考试信息栏”开关（默认开启）可隐藏普通日程和考试的信息栏文字、斜纹与
边框，同时取消其左侧排版预留（占位改为 `[真实开始, 真实结束]`）；
隐藏时绘制面仍向左额外保留一个线宽，开始标线按真实位置保持可见，
结束标线、时段斜纹和点击区域不受影响，DDL 与仅开始时间项目不受该
开关影响。

## 与主线滚动／性能实现整合

泳道先按上述完整区间分配一次，缩放只更新绘制投影，不重新分配泳道。
普通 DDL 和日程左信息区保持定宽，真实时间段才按缩放伸缩；不能照搬
主线日历天数拖尾随缩放扩张或邻卡裁短信息区的规则。纵向范围仍取全局
最高泳道，不依赖横向可见条目。

纵向拖动、惯性和回弹交给 Flutter ScrollPosition；正常 overscroll 可保留，
筛选／尺寸缩小导致的失效偏移则与裁剪同步纠正。平移只更新视口局部，
网格文字及卡片文字层可复用；双标线和斜纹的动态几何不能缓存为旧位置。
自定义颜色由主线能力提供，完成透明度仍乘原 alpha。

## 验证

回归测试覆盖时间规则、精确边界、跨日/跨年、单时间点、原始存储不变、
实时设置投影、关闭恢复、设置持久化/竞态/异常、中文英文窄屏和时间选择器，
以及排版区间、定宽主体、缩放延伸、裁剪、双标线重叠和完成透明度。

本地没有 Flutter SDK 时仅进行静态核对，不将补丁检查或推送成功表述为
测试通过；运行结果以 GitHub Actions 的分析和测试为准。
