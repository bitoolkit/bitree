# DDL 每日伪截止时间段

## 时间规则

设置默认关闭，预置每日 22:00–次日 08:00。开关、开始和结束分钟作为一份
JSON 设置保存；关闭仍保留所选时间。

区间两端包含：开始早于结束时匹配同一天；开始晚于结束时匹配跨日区间，
凌晨截止归到前一天的开始时间。开始与结束相同时仅匹配该时间点，不代表
全天。设置精度是分钟，边界时刻为该分钟的 00 秒：结束时刻包含，但其后
的秒和微秒不包含。

只对有真实截止时间的 DDL 生效；普通日程、考试、仅开始时间的测验不变。
全天 DDL 的真实截止仍按原规则视为下一天 00:00，因此也可命中跨日窗口。

## 数据与显示

`AgendaEntry.startsAt`、`allDay` 及序列化内容保持原始数据。
`realDueAt` 是原始截止；`dueAt` 是派生有效截止；`scheduledAt` 用于实际
调整后的日期分组和排序。生效配置只作为运行时投影，不写回日程存储。
关闭或更改设置总是从原始时间重算，不能累计伪提前，也不改变平台链接、
提交状态或同步匹配。

命中窗口与实际提前分开表示：起点或单时间点命中时，即使没有提前，仍需
处理两条标线的绘制顺序。详情中实际发生提前时同时说明有效和真实截止，
编辑器继续编辑原始时间。

## 泳道图

命中窗口的 DDL：

- 预留区间为 `[有效截止 − 4 天, 真实截止]`。
- 左侧主体沿用最小缩放 3.75 天的屏幕定宽规则，不随缩放增长；右边界
  位于有效截止，受影响条目使用固定 4 天而非自定义拖尾长度。
- 两条标线之间按真实时间间距绘制矩形，宽度跟随时间轴缩放。
- 填充为屏幕定宽的 45° 宽斜纹，同一配色、交替透明度；完成后再衰减。
- 真实标线未完成时使用原标线的 0.5 透明度，完成后再衰减为 0.25。
- 真实标线在最上层绘制，包括零间距或小于标线宽度的情况；零间距没有
  斜纹区域。有效标线及左侧主体保留正常完成/逾期规则。
- 延伸段按视口裁剪，不能创建按时间跨度无限扩大的画布；全局泳道高度
  规则保持不变。

## 验证

回归测试覆盖时间规则、精确边界、跨日/跨年、单时间点、原始存储不变、
实时设置投影、关闭恢复、设置持久化/竞态/异常、中文英文窄屏和时间选择器，
以及排版区间、定宽主体、缩放延伸、裁剪、双标线重叠和完成透明度。

本地没有 Flutter SDK 时仅进行静态核对，不将补丁检查或推送成功表述为
测试通过；运行结果以 GitHub Actions 的分析和测试为准。
